# Custom sentences and intents in Home Assistant

Custom sentences and intent scripts are an alternative to automations for controlling voice assistants. 

[This repository](https://jackjourneyman.github.io/Custom_sentences_and_intents_in_Home_Assistant/) contains some some simple, practical examples of what they can do, including setting timers and alarms and managing shopping lists.

Please use the [discussions page](https://github.com/jackjourneyman/Custom_sentences_and_intents_in_Home_Assistant/discussions) for comments or suggestions.
